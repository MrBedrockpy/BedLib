## BedLib

BedLib - это новая переработанная версия моей библиотеки для комфортного и быстрого создания плагинов для Paper-совместимых ядер для Minecraft. Я полностью переписал системы для конфигураций и менеджмента данными. 

### Почему вам следует использовать эту библиотеку?

1. Эта библиотека стандартизирует любой плагин, до единой структуры в проекте плагина.
2. С этой библиотекой вы сможете в разы быстрее написать плагин любой сложности
3. Эта библиотека в сборке включает в себя лучшие решения для обработки команд в чате (LiteCommands) и для создания меню (InvUI)
4. Эта библиотека предоставляет формат для текста, который одним вызовом метода конвертируется во все форматы, существующие в Minecraft
